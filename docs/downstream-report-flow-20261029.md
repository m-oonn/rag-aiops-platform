## 改动及原因

1. `unresolved_questions()` 以前只保存下一检查的问题和预期观察。已执行的检查因问题仍未解决而继续列出时，没有说明检查已完成。现在依据本轮执行记录，分别说明尚未执行、检查已执行但问题未查清、工具失败且尚未取得有效结果。失败理由优先，执行完成不当作查清原因；不改调度、证据门槛或两项机制。三项反例先失败后修复。
2. AIOps 未决问题原来未消费 `expected_observation`、`evidence_ids`。现在展示预期观察并复用 `focusEvidence` 定位问题依据；旧记录缺字段保持兼容。不增加原文读取权限。新增前端断言先失败后修复。
3. 隔离浏览器两次复现引用已获得焦点但仍在视口外。折叠过渡结束时，组件尚会清除高度约束，立即平滑滚动仍可能按变化中的布局定位。现在过渡后下一动画帧重新检查焦点与展开状态，再立即对齐；避免焦点已转移时抢回位置。单测核对帧前不重滚、帧后立即对齐，真实浏览器复验通过。

调用链保持 API / service / graph → investigation 结构化诊断 → report、complete 事件 → Vue；刷新经所有权校验 → SQLite 报告与 checkpoint 诊断 → 同一页面组件。未修改原始模型提议、工具参数、旧报告、费用账本或人工审核表。
