# 调查卡片证据定位与不完整结果提示

2026-10-26，在 `main` 当前工作树完成。调查卡片中的故障发现和中性观测摘要，现在均可点击证据编号，展开证据账本、滚动到对应记录并转移键盘焦点。沿用 `focusEvidence`，因此候选、机制事件和报告中的既有引用也使用修正后的定位流程。

## 改动与行为

- `frontend/src/views/AIOps.vue`：两类摘要引用改为按钮，支持键盘 Enter 和鼠标；账本记录可聚焦并显示轮廓。折叠展开的 `max-height` 动画结束后，再将已聚焦记录滚动到可见区域，避免仅在 `nextTick` 后定位时可滚动高度尚未稳定。
- 摘要缺少编号时显示无法定位；编号不在当前账本中时提示刷新，不自动请求原始返回。时间缺失显示“采集时间未知”。旧记录未提供新增字段时继续兼容。
- `truncated` 提醒结果不完整，不能排除未显示的问题；`error` 以文本显示并提示不能据此判定对象正常或异常，不作为 HTML 执行。
- `frontend/src/views/AIOps.test.js`：覆盖引用定位、焦点、动画结束、正常记录无警告、截断、错误文本转义及缺失引用，不通过获取原文完成定位。

本轮只消费已有字段，不改 API、后端、调度、模型上下文或结论门槛。当前后端摘要的 `error` 来自已有 `payload.error`；HTTP/TCP 探测失败还可能是摘要中的现场结果，不能一概解释为采集失败，也不因此确认根因。
