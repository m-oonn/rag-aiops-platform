## 首次发现与修正

初次 13 项检查为 10 项通过、3 项失败：

1. 角色切换重绘报告后，原证据按钮被替换，抽屉关闭无法恢复焦点。现保存稳定定位信息，并在关闭时重新定位；背景在抽屉打开时设置 inert。
2. HTML pattern 的连字符没有按 Chromium 的 Unicode Sets 规则转义，产生控制台错误。已转义，并在按 ID 恢复路径重新检查。
3. 验证脚本误以为 CLI 沙箱提供 Node Buffer，文件登记检查未执行。改用本目录的小型文本夹具；原型文件登记逻辑未因该错误修改。

首次打开时还发现 favicon 404，已使用内联空图标消除。当前结果由修正后的独立页面重新载入产生；没有把首次失败改写成通过。

## 查看与复现

直接双击 `index.html` 即可评审。需要重跑浏览器检查时，在项目根目录启动静态服务（脚本默认端口 8768）：

```powershell
.\.venv\Scripts\python.exe -m http.server 8768 --bind 127.0.0.1 --directory docs/prototypes/aiops-v1
```

在另一个终端运行：

```powershell
playwright-cli -s=aiops-prototype open http://127.0.0.1:8768/
playwright-cli -s=aiops-prototype --raw run-code --filename=docs/prototypes/aiops-v1/verify-browser.js
playwright-cli -s=aiops-prototype close
```

脚本中的绝对路径对应当前工作区；迁移目录后应调整。静态服务器与浏览器均只是本次本地验证工具，不是产品部署。
