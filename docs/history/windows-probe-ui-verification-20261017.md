# Windows Probe 页面与权限验收（2026-10-17）

本轮验证真实 Probe 数据如何进入证据账本、API 和页面。未调用模型，没有发起真实自主诊断，也没有制造业务故障。

## 实现变化

- AIOps 页面保存最近完成运行的编号，刷新后通过拥有者校验的 API 恢复报告与证据；待审批运行同样恢复证据。
- 刷新证据状态时，持久化数据覆盖同 ID 的旧 SSE 元数据，更新过期状态，避免重复条目。
- 页面显示目标在线、离线、状态过期或不可用，以及最后连接消息时间；状态通过已有目标接口读取。
- 审计/admin 运行拥有者可按需展开脱敏现场证据，普通运行拥有者只能看摘要；服务端仍负责最终权限判定。
- 步骤回放接口增加运行拥有者检查，防止绕过证据权限。
- 网关每次基线上报更新目标 last_seen；数据库目标超过 180 秒无消息时返回 stale。
- 执行器按当前配置的目标校验 Probe 证据，拒绝其他目标；证据 SSE 摘要统一脱敏。

## 真实链路

1. Windows LocalService Probe 通过已安装网关和真实 MCP adapter 返回 EventLog 服务状态、资源数据。
2. 使用现有执行器 _record_probe_evidence 完成校验、入账，创建明确标识为页面验收的运行，未用模型生成答案。
3. 为普通用户、审计用户分别创建独立验收运行。验收使用 Docker 卷中的独立 SQLite，API 与网关共用该库；没有修改现有业务运行。
4. Edge 浏览器通过真实登录 API 获取会话，无路由 mock、无鉴权绕过。页面能恢复每个用户的两条证据，显示 windows-local-01、windows_probe、采集时间、服务与资源摘要，以及来自真实心跳的在线状态。
5. 两个用户访问对方证据均得到 404。普通用户没有现场证据展开按钮；审计用户按需展开并读到含 probe_target 的文件内容。两种用户刷新页面后均恢复两条证据。
6. 实际重启验收 API 容器，保留浏览器登录和运行编号。刷新后仍恢复两条证据、目标状态与审计文件读取。此结果证明本轮账本/API 恢复，不替代 LangGraph 调查或待审批 checkpoint 恢复验收。

截图位于 runtime/probe-ui-20261017-091830/user-evidence.png 和 auditor-evidence.png。截图时现场证据已超过 180 秒，页面正确显示过期，同时目标继续收到新基线而在线。在线不代表历史证据仍新鲜。

## 验证结果与收尾

- 后端全量离线回归 383 passed、99 deselected；随后新增 SSE 脱敏测试，相关 evidence 测试 4 passed。未把这次定向检查冒充最终版本全量重跑。
- 前端 84 tests passed，生产构建通过；保留既有 bundle 体积警告。
- 网关镜像构建通过，git diff --check 无空白错误；有既有 CRLF 提示和 PyMilvus 弃用警告。
- 验收中 Chrome 自动化退出，改用已有 Edge；首次 API 容器只连 internal 网络导致本机代理不可达，增加本机验收网络后可达；连续登录重试触发现有限流，保留限流设置后验收通过。
- 临时 API、Vite 和验收浏览器已停止；网关恢复原 compose-db/rag_system.db，验收数据库、运行记录和截图保留。常驻 Probe 保持运行。凭据未写入本报告。

## 尚未证明

没有真实模型自主选择检查、调查换方向与定位根因的验收；没有新配置业务服务/日志/依赖，没有执行隔离 Windows 八类故障盲测。知识库参与 Windows 调查、生产 WSS/TLS、整机重启自启仍需分别验证。

## 后续调查链路复核

页面验收后继续追踪正式调用链，修复了以下缺口：

- Probe 单独启用时也创建持久运行并进入自主调查策略，不因此自动打开终端权限；规划阶段 inventory 写入证据账本及证据事件。
- 调用 Probe 工具时校验返回的 operation 与工具相符，同时检查目标、来源、平台、时间和 hash；调查策略引用 Probe 数据时再次校验，拒绝过期或错误目标。
- 知识库作为参考资料保留引用，不能单独充当现场证据；调查证据索引只接受指定现场来源。
- Probe 启用时过滤接受任意地址或业务 POST 的旧探测工具，保留配置白名单依赖探测。
- 修复 HTTPS 的 TLS 参数错误传给 ClientSession，改由统一装配层传给 HTTP 客户端工厂；默认仍校验证书。测试验证实际客户端构造参数，本轮没有真实 TLS 握手验收。
- MCP 配置日志仅记录服务名，缓存标识使用摘要，避免日志输出认证配置。

新增确定性流程测试运行真实 LangGraph 和 SQLite checkpoint，替换模型与采集输入，验证 Probe 单独启用时的调查策略、证据事件、拥有者运行记录和 checkpoint 重新打开。它不能证明模型自主调查能力。

另一次真实 MCP 验证通过统一客户端与执行器读取 EventLog=running，并将新鲜证据放入调查索引；将同一返回的 target_id 改成错误目标后索引拒绝。模型调用次数为 0。

最终后端全量离线回归：394 passed、99 deselected，23.24 秒。前端本轮 84 passed、构建通过。常驻 Probe 保持 LocalService Running；网关使用原数据库，临时验收 API、Vite 和浏览器已经停止。真实模型本轮费用授权与首个业务对象的问题已向用户发出，未收到答复前不执行依赖这些信息的操作。
