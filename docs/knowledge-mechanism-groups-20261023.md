# 固定知识条件与四组机制联合核验

日期：2026-10-23。本轮是免费程序行为验收，模型决策及 Probe 输入固定；不是正式四组效果实验。

## 实际改动

既有 save_mechanism_audit 只保存配置、候选跟踪与执行步骤，不能复核各轮可见的知识。现于 scripts/evaluate_windows_probe.py 中补保存每轮 knowledge_context 的脱敏片段、确定性 JSON SHA-256 与机制选定的 next_tools。保留原审计语义与旧调用接口；passed 仍仅表示配置/轨迹一致，不自动判断跨组知识相同或证明机制有效。知识指纹反映实际进入有界上下文的内容，不代表整个语料库版本或全部运行条件相同。

tests/test_agent_knowledge_consumption.py 复用真实三份 PDF 的隔离入库与本地检索，新增三类场景，每类在 G00/G10/G01/G11 中经正式 service.execute、planner、executor、replanner、工具守卫、证据入账与 SQLite checkpoint 运行。各组模型替身代码相同，不读取组别；仅独立开关不同。机制事件由正式规则生成，不预写事件。测试没有替换生产图节点，也没有通过 DefaultReplanStrategy 实现 G00：PROBE_ENABLED 将全部四组路由到同一自主调查策略。

这些固定决策特意构造候选遗漏与现场反证机会，仅作工程回归，不能作为控制器隐藏答案或真实自主模型实验样本。
