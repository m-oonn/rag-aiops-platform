# 预测、调查与报告链路收尾（2026-10-30）

按用户“推进步幅大一些，减少反复测试核验”的要求，本轮一次处理模型输入契约、候选验证、检查结果消费、报告、SSE和页面显示；只验证受影响链路，不新增付费调用、故障现场或服务重启。

## 具体改动

- `src/agent/aiops/strategies/investigation.py`：在模型schema与提示词同时明确合法操作、字段、类型和值。TCP只接受 `ok/failed`，不把 `success` 猜改为 `ok`。无效条件或空对象保留原提议、保持未验证，记录具体拒绝原因，不参与假设保护或矛盾改向；当前合法检查仍可独立继续，不为纠错增加模型调用。
- 未决问题复用具体查询记录：事件通道未配置就写实际配置阻碍；同参数查询已有结果，即使模型换检查名称也不能再称为尚未执行。执行记录、已有观测和因果解释仍分开。
- 最终文字中的“待核实矛盾”改为“待核实说明（不作为可靠反证）”。旧JSON字段 `contradictions` 保留兼容，真实反证调度仍由现场条件判断，不把空日志或缺少退出历史当作可靠矛盾。
- `src/agent/aiops/events.py` 与 `frontend/src/views/AIOps.vue`：实时及刷新调查摘要展示校验说明，沿用原来的脱敏与因果原句过滤；最终页面统一使用“限制与待核实说明”。旧checkpoint没有新字段时照常读取。
