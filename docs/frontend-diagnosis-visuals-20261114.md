## 已实现

- 浅色平面布局、细分隔线、无卡片；已有报告时折起现象输入，释放图形区域。
- 报告优先呈现后端结论层级、去重异常观测、现场关系和去重处理建议；操作前确认、影响、验证步骤按需展开，完整报告仍可读取。
- 采集回放按证据采集时间排序，区别于计划列表；支持暂停、前后选择、到尾停止，切换视图或卸载清除计时器。服务图仅逐步展示当时已取得的观测。
- 证据按对象分组，日志解析为事件时间链，保留采集时间与事件发生时间的区别；配置和进程结构化展示。截断 JSON 和缺失计数保留未知，历史 TTL 失效不显示成采集失败。
- 候选图读取明确的支持／反驳关系；引用和检查关联本身不等于支持。保留后端 active／excluded／supported 状态，现场条件与原因解释分别标记，不产生置信度或自行确认原因。
- 关系图只连接当前证据中能映射的本机日志端点，标记“日志配置指向 · 因果未确认”。没有观测的 edge 依赖不补造连线。
- 证据详情保留所有权接口和角色限制，普通账号不展示原文；角色撤回清除原文。刷新、新建、流式晚到响应均按当前运行隔离。
- 支持键盘页签导航、焦点环、减少动效，以及容器宽度变化时的图形重排。
