# G11 候选契约与重复查询修复（2026-10-30）

本轮修复真实 DeepSeek G11 暴露的候选无法参与机制、查询参数比较不准确两个代码问题。没有新增付费调用；原单场仍为未完成，不能把本次离线验证记作真实模型诊断成功。

## 候选进入机制的条件

原实现要求模型同时输出自然语言解释和完全相同的公式文本。真实模型附有结构化条件，但解释使用自然语言，导致七轮候选全部未绑定。

现在由程序从合法的 `condition` 构造有限预测，例如 `dependency_probe/downstream: tcp == "failed"`，用于候选身份、保护和矛盾判断。自然语言原文保存在 `source_explanation`、`source_explanations` 和未改写的 `model_suggestion` 中；同一预测的多个解释完整留痕。文字改写且条件不变时可沿用身份，显式 ID 仍须属于本次调查，不允许更换对象或抹去原预期。

这是有限预测的支持或反驳，不是自然语言因果主张的验证。缺少合法条件和明确对象时不猜补可执行机制候选；报告中的自由文本因果结论仍保持原门槛。公开报告及 SSE 不携带新增的原始解释字段。轨迹升级为 `version=3`，行为审核核对生成的预测、保存条件及全部原始解释，旧轨迹按版本保留兼容。

涉及入口：`src/agent/aiops/strategies/investigation.py`、`src/agent/aiops/events.py`、`scripts/mechanism_behavior.py`。

## 重复查询的实际边界

`executor.py` 调用共享的精确参数比较函数，分别处理各工具默认参数。修正文本日志请求 `lines` 与返回 `line_limit` 的对应关系，按 Windows 规则统一路径大小写、斜杠和点目录；查询不同对象、日志、行数、窗口、端口过滤或排序不会被混为同一次查询。过期、目标不符或采集错误的返回不计入重复依据。

策略保留一次复核：允许首次查询和一次确认，最近两次同参数有效观测内容相同时拦截第三次。自主执行器逐条消费本步结果，再判断下一条，同批或同一步不同 ReAct 轮次不能绕过门槛。拦截记录只保存一次；普通非自主执行保留已有并行路径。

**限制：原单场 14 次调用没有第三次参数完全相同的查询，本规则不会拦截其中任何一次。** 它修复比较错误和循环漏洞，不证明已经降低原场的请求量；跨对象但鉴别力不足的检查仍需真实调查验证，不能仅凭离线测试宣称已解决全部低效问题。
