1. 配置错误已被工具读到，但原报告先展示入口 HTTP 失败，关键 ValueError 日志埋在后面。策略现在在停止原因之前展示当前、范围内、成功取得的文本日志，保留路径、证据 ID、展示限制；明确应用自述不自动证明因果。

3. 仅改提示仍不足，新增健康提议被拒后的单次校验反馈；仍调用原裁决、身份、权限、引用及健康门槛，不直接改成成功。纠正机会按每次 decide 计算，不代表整场最多一次。反馈与结果写入行为轨迹，四组共用，不算保护或矛盾机制收益。
