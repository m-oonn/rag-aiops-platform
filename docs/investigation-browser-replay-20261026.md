## 失败与修正

首次pytest因遗漏创建输出父目录，24项均在准备阶段报错；建目录后才得到上述24项通过。不是诊断逻辑失败。

浏览器脚本先遇到CLI执行环境缺少 `URL` 对象，随后宽泛拦截规则误挡 `/src/api/index.js`。改用字符串解析路径，并限定拦截到本机根路径 `/api/`；关闭本人创建的隔离浏览器后重新执行。失败过程中一次POST到达本机API并返回401，被登录校验拒绝，未进入诊断。失败控制台和错误信息分别保留为 `browser-attempts-1-2-console.txt`、`browser-attempt-1-error.txt`、`browser-attempt-2-error.txt`；不能把成功轮“转发0次”推广到全部尝试。
