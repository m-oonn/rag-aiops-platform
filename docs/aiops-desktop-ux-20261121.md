## 范围与方法

先读 [功能连续性记录](aiops-functional-improvements-20261118.md)、[工作区设计](frontend-aiops-workspace-20261113.md) 和 [报告易读化](frontend-readable-report-20261114.md)，再走查新建、历史、报告、证据与原文、排查和回放、候选、人工复核、终端审批、工具账本、知识对照及经验审核。工作台 AIOps 区域及主导航只核对入口，未扩大改动。沿用项目按钮、状态、弹窗和表格原语，不照搬其他模块的操作布局。

使用现有本地前端，Chrome 通过 Playwright 操作实际页面；主要素材为已保存的诊断和证据，异常、等待、写入响应通过浏览器内 API 拦截模拟。没有重新编译或构建，没有改后端或调用真实模型、终端、人工审批和知识库写接口。
