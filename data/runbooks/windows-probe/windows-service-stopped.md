# Windows 服务停止或未运行排查

这是排查顺序参考，不是当前主机事实，不能单独支持根因结论。

1. 先用 Probe 的 `services` 查询配置中登记的服务，记录 `target_id`、采集时间、服务状态和错误字段。
2. 如果服务不是 Running，再查该服务对应的进程和端口，区分“服务停止”“进程退出”和“端口未监听”。
3. 查询配置白名单中的 Windows Event Log，优先看服务控制管理器和应用错误事件，核对事件时间是否覆盖故障窗口。
4. 只有服务状态、进程/端口现场和相关日志相互支持时，才能报告服务未运行是当前证据支持的解释；否则报告证据不足。

Probe 只读，不自动启动、停止或重启服务。修复动作必须走审批流程。
