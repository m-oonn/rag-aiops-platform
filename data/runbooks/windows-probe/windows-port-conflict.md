# Windows 端口未监听或端口冲突排查

这是排查方法，不是现场结论。

1. 先对配置中的入口做 DNS、TCP 或固定健康检查，分别记录失败类型；TCP 成功不等于 HTTP 健康。
2. TCP 失败时查询 Probe 端口快照，确认目标端口是否监听以及是否能取得 PID；端口快照被截断时不能证明端口不存在。
3. 若端口被其他进程占用，交叉核对进程名称、PID、服务状态和应用启动错误日志。
4. 只有端口归属和启动失败日志共同支持时，才能报告端口冲突；缺少日志或 PID 时保留未决解释。

Probe 不执行 `netstat`、PowerShell 或结束进程。释放端口、修改绑定和重启服务必须审批。
