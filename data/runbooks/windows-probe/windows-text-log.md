# Windows 白名单文本日志排查

文本日志是现场证据来源之一，手册本身不是现场结论。

1. 只读取本机配置登记的日志路径和文件通配范围，确认实际路径没有越界、链接或网络共享，并记录采集时间。
2. 先取限定大小的尾部内容，再按故障时间、错误级别和服务关键词筛选；记录是否达到行数或字节上限。
3. 将日志原文与服务状态、进程、端口和依赖探测的时间对齐；同一错误可能是下游故障的表现，不能单独等同于根因。
4. 日志缺失、权限不足、文件轮转或输出截断时，明确说明限制并保留未决解释；不能为了得到结论扩大路径白名单。

Probe 只读取尾部并做凭据脱敏，不上传未授权文件、不写入日志、不执行任意 shell。
