# Windows Event Log 异常排查

这份手册只说明取证顺序，不能代替目标机上的事件原文。

1. 只读取本机配置允许的 channel 和 provider，记录 `target_id`、采集时间、查询时间窗和返回条数。
2. 先按服务名、错误级别和故障时间筛选，再把事件 ID、provider、level、message 原文与服务状态、进程和入口探测对齐。
3. 事件日志没有结果不等于系统没有错误：channel/provider 白名单、时间窗、权限和条数上限都可能造成缺失；截断时不能据此排除解释。
4. 只有事件原文与其他现场证据在同一时间窗相互支持时，才能把事件作为根因证据；单条通用错误事件只能作为线索。

Probe 只读白名单日志，不读取全部日志、不修改日志配置、不清理事件，也不执行 PowerShell。
